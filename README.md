# Haniye Maghsoumi — Animated Portfolio

Astro + HTML/CSS/JS single-page portfolio designed for GitHub Pages.

## Run locally

```bash
npm install
npm run dev
```

## GitHub Pages

1. Replace `YOUR-USERNAME` and `YOUR-REPO` in `astro.config.mjs`.
2. The stylesheet is served from `/YOUR-REPO/styles.css`; if you use a custom domain, change it to `/styles.css`.
3. Build with `npm run build`.
4. Deploy the generated `dist/` folder with GitHub Pages.

The page uses only Astro, HTML, CSS and vanilla JavaScript. No animation framework is required.
